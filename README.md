Descripción

Implementación comparativa de distintos enfoques para el problema de optimización de rutas, incluyendo un algoritmo de fuerza bruta, una heurística de nearest neighbour y una mejora con 2-opt. El propósito del proyecto es revisar su comportamiento y desempeño de manera general, sin detallar la lógica interna.

Ejecución

Para ejecutar el proyecto de forma local:

Clonar el repositorio.

Instalar dependencias:

npm install

npx http-server .

Dar click en alguno de los links que da la terminal o ir directamente a localhost:8080
